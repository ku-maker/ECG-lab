# 学習機能の確認記録

更新日：2026-09-10。

## 1. 心拍数と波形の幅

rateTiming.ts の正方向・逆方向の時間変換を、描画、QRSイベント、強調位置、描画の追加サンプル位置で共有します。P波の始まり（P波のないテンプレートはQRSの始まり）からQRSの終わりまでの幅は、基準BPMでの幅を保ちます。その前後の時間を配分して1拍の長さを変更します。

基準BPMは正常60、洞性徐脈45、洞性頻脈120、VT160、固定SVT180です。接合部調律のテンプレートは60 bpm相当のQRS幅を保持します。AFなどの合成波形では、もともと固定だったQRS形態を引き続き使います。Wenckebach型の段階的な遅延は、BPM比例から固定時間へ変更しました。

1度房室ブロックとWenckebach型の操作範囲は40〜100 bpmです。PAC/PVCは、通常拍のQRSが終わってから早期拍に移るよう開始位置を調整しました。PACにも固定幅の時間変換を使います。

これは臨床的に検証された生理モデルではありません。ST・T波付近も時間配分で変わり、特に速い設定では強く圧縮されます。実際のPR/QTの変化を予測する用途には使いません。間隔の定義は [Clinical Methods — Electrocardiography](https://www.ncbi.nlm.nih.gov/books/NBK354/) を参照しています。

## 2. 計測練習

対象は正常洞調律・洞性徐脈・洞性頻脈・1度房室ブロックの4症例です。PR、QRS、RRの課題を選ぶと一時停止し、手動計測ができます。ヒントは強調表示と同じ基準位置を使います。

画面内に全体が収まる区間を対象に、選択順に依存せず始点・終点の時間座標をそれぞれ±20 msで判定します。高さは判定しません。同じ長さでも異なる場所の2点、1拍飛ばした2点は一致としません。評価値は教育用モデルの基準位置であり、患者波形の自動診断ではありません。

再生、症例・BPM変更、通常の観察ステップへの移動で練習を終了します。練習結果と手動計測点は保存しません。

## 波形から刺激伝導の時点を選択（2026-09-13）

刺激伝導画面の正常洞調律の波形をタップ・ドラッグすると、既存の共通時計を停止して指定した位相へ移動します。同じ位相を3D・波形カーソル・説明・時間スライダーへ渡します。既存の段階ボタンと時間スライダーも引き続き利用できます。左右キーで5 ms、Shift併用で40 ms、Home／Endで周期の先頭／末尾へ移動できます。

描画領域の余白を除いて座標を変換し、末尾は999 msで止めます。3種類の表示幅でP・R・Tの時刻、範囲外の座標、停止への遷移、既存の3Dと波形の共通位相を自動検証しました。対象は正常洞調律の模式モデルです。ブラウザでのタッチ・ドラッグ操作確認は未実施です。

## 3. 判断理由のクイズ

全17症例に、そのプリセットの観察項目に対応した3択を用意しました。症例名を答えた後に出題し、理由の回答またはスキップで解説を開きます。理由の選択は次の問題・範囲変更でリセットします。

理由の回答を症例名の正答率に混ぜません。設問は典型例の観察練習で、同じ診断名のすべての患者波形に所見を一般化するものではありません。参考資料は既存の症例別資料を共有します。

### 根拠別の復習（2026-09-13）

既存の `ecg-lab.quiz.v1` に任意の `reasonAttempts` を追加しました。古い成績をそのまま読み込めます。症例名・根拠はそれぞれ直近100回答を保持し、根拠の履歴には選択した文章と正誤を表示します。根拠のスキップ・未回答は記録せず、直前までの復習対象も変えません。

各症例の最後の根拠回答が不正解なら、5つの観察ポイント別に復習対象へ追加します。現在の出題範囲に含まれる症例だけを出題します。症例名の正解では根拠の苦手を解除せず、根拠の正解で解除します。次の問題へ進む際に対象がなくなっていれば通常出題に戻ります。範囲変更で復習モードを解除し、成績リセットでは両方の履歴を消去します。

互換性、履歴の上限、症例名と根拠の独立性、不正な保存値の除外、全17症例の分類、範囲を守った出題、根拠の正解による対象解除を自動テストで確認しました。型チェック・Lint・本番ビルドも通過しています。今回のブラウザ操作は利用上限による自動承認審査の拒否で実施できず、画面上の操作確認は未実施です。

## 4. 設定の保存

ecg-lab.learning.v1 に、学習症例・BPM・停止状態・観察ステップ・学習とクイズの表示配分・クイズ範囲を保存します。再読み込み後は学習画面を開き、クイズへ移ると保存した範囲を使います。音声は再開時にミュートです。

読み込み完了前に初期値で上書きしないよう、クライアントの準備後に設定を読み込んで画面を生成します。バージョン、症例、数値、ステップ、範囲を検証し、無効な値は初期値または操作範囲へ補正します。ストレージを利用できない場合はページ内で継続し、保存できない状態を表示します。

「学習設定を初期化」は、この設定だけを戻します。クイズ成績は別のキーで保持します。複数タブでの設定の同期は対象外で、最後に保存した設定が次回の読み込みに使われます。スクロール位置はページ内のみ、波形時刻・SHOCK・計測点は復元しません。
