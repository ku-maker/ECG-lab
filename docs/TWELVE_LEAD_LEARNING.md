# 12誘導判読・初版（2026-09-13）

## 根拠と範囲

- 表示・技術の参照：Kligfield et al., AHA/ACC/HRS, 2007, https://doi.org/10.1016/j.jacc.2007.01.024 。25 mm/s・10 mm/mVの比率、校正表示、12誘導を使用。3行4列の各列は**同一時刻**を表示する。連続する時刻の列配置ではないことを明示。
- 脚ブロックの参照：Surawicz et al., AHA/ACCF/HRS, 2009, https://doi.org/10.1016/j.jacc.2008.12.013 。所見の説明はMerck Manualの脚ブロック解説（2024年レビュー）も参照。https://www.merckmanuals.com/professional/cardiovascular-disorders/specific-cardiac-arrhythmias/bundle-branch-block-and-fascicular-block
- 心房細動と房室ブロックの観察項目：Merck Manual Professional Edition。https://www.merckmanuals.com/professional/cardiovascular-disorders/specific-cardiac-arrhythmias/atrial-fibrillation 、https://www.merckmanuals.com/professional/cardiovascular-disorders/specific-cardiac-arrhythmias/atrioventricular-block
- 学習用の「記録→リズム→軸→間隔・QRS→ST・T→総合」はアプリの設計であり、学会指定の教育カリキュラムとは称さない。全診断基準の実装・ガイドライン準拠認証ではない。

## 教材

PTB-XL v1.0.3 の500 Hz・10秒・12誘導を6件使用。正常2件、完全右脚ブロック1件、完全左脚ブロック1件、心房細動1件、第1度房室ブロック1件。原データの主診断ラベルの確信度100、人による検証あり、fold 9/10、選択したノイズ注釈なしを条件に選択。提供元の検証と、今回追加した解説の医療者レビューは別であり、後者は未実施。

データはCC BY 4.0。public/ecg/ptbxl/ATTRIBUTION.mdに出典、変更内容、原著・PhysioNet引用を記載。LICENSE.txtを同梱。selection.jsonは選択した元注釈のみで、患者属性は含めない。データ提供元のラベル以外の診断を自動生成しない。

## 操作と制限

上部「12誘導」から開く。全誘導の共通2.5秒区間を0・2.5・5・7.5秒から切替。選択誘導の10秒拡大。電圧スケールは誘導間で共通、各小マスは40 ms・0.1 mV。画面の実寸mmは保証せず、幅不足では縮小せず横スクロール。追加のフィルタ・間引きなし。

所見メモ、根拠誘導、第一候補、根拠文、別に考えた診断、除外・保留した根拠を記録してから提供元ラベルと照合。自由記述・根拠誘導の正しさは採点しない。診断名の一致を判読能力の認定に使わない。回答時または「回答・メモを保存」で症例ごとに最新の入力を保存する。未保存の編集は症例切替・モード移動・再読込で消去。従来クイズの成績とは別。学習対象6件に限定し、未提示の病態を鑑別できる試験とは扱わない。

急性虚血、治療判断、房室ブロックの3D再現、症例ごとの自動計測・境界の自動採点、AIによる所見採点は対象外。

## 検証と再現

`scripts/import-ptbxl-lessons.py /path/to/downloaded-records` で元.hea/.datから変換する。取得元はJSONのsourceRecordを `https://physionet.org/files/ptb-xl/1.0.3/` に連結。変換時にデータ長、各誘導の初期値、WFDBチェックサム、欠損サンプルを検証する。

`npm run verify:twelve` は12誘導の重複・欠落、6記録のサンプル数、ゲイン・基線変換後のチェックサム、全4時間区間、時間・電圧座標を検証。原データは3D投影・既存シミュレーターとは混ぜない。

2026-09-14に6症例ボタン、新規2記録の読み込み、回答選択肢、鑑別欄、旧保存データの表示を実画面で確認。個別の医療者レビューは未完了であり、試行版として表示。


## 比較・計測・復習の追加

2誘導を上下に並べ、同じスクロール領域で表示。校正・区間を共通にして10秒または一覧の2.5秒区間へ切り替える。V1/V6、I/aVFの組み合わせボタンを用意。解説からは対応する誘導の10秒全体へ移動し、フォーカスも移す。未検証の波形境界を強調する機能は加えていない。

計測領域は校正波の32 SVG単位を除いた波形部分に限定。1秒100単位・1 mV 40単位で描画と計測を一致させる。2点の時間差と電位差を示す手動計測で、始点・終点は利用者が選ぶ。誘導・区間変更やクリアで計測点を解除する。計測点は保存しない。

保存キーは `ecg-lab.twelve.v1.<症例ID>`。観察メモ5項目、根拠誘導、判断、根拠文、振り返り、回答済み状態を保持。文字数上限5,000、誘導・選択肢・バージョンを検証して復元する。手動保存と回答時保存を用い、保存失敗はその場で知らせる。同症例への再挑戦はフォームを空にし、前の保存記録は次の保存時に更新する。履歴を無制限に蓄積する機能ではない。

保存値の往復・異常値・文字数上限と、2.5秒／10秒それぞれの計測座標を `verify:twelve` で検証。実画面では保存一覧、未保存警告、再読み込み後のモード・保存回答復元を確認済み。

## 学習表示と虚血・梗塞部位（2026-09-15）

12誘導画面を「まず波形を学ぶ」と「問題を解く」に分離した。学習表示は提供元ラベル、見る誘導、判断の目安、鑑別、見落としを波形と同時に示す。問題表示は答えを隠し、従来の回答・保存機能を使う。

部位対応表は前壁中隔（V1〜V4）、側壁（I・aVL・V5・V6）、下壁（II・III・aVF）を示す。後壁はV1〜V3の鏡像変化から疑いV7〜V9、右室は下壁変化から疑いV3R・V4Rで直接確認する。対側性ST変化は補助所見として反対側の誘導と照合し、単独で部位や急性冠閉塞を確定しない。

## 学習タブと4択クイズの分離（2026-09-15）

メインナビゲーションを「12誘導学習」と「12誘導クイズ」に分離した。学習では症例プリセットから疾患・部位を選び、実波形、観察誘導、判断目安、鑑別、見落としを同時に表示する。クイズでは同じ14記録のラベルを隠し、同じ分類内の4択を提示する。回答後に正解、3段階の判読手順、鑑別を表示し、次の問題へ進む。
